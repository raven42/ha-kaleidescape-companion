# Documentation screenshots

These supplied PNG captures illustrate the project README and user guides. Keep
their original resolution and aspect ratio so interface text stays readable when
opened at full size. Documentation uses linked Markdown images, which fit the
available text column in GitHub's renderer and open the full-resolution capture
when selected.

Place each image beside the task it illustrates, with descriptive alt text and a
short caption explaining the visible state. Treat titles, counts, dates and
enabled features as examples, not setup requirements. Update the image and
caption together when the interface changes.
