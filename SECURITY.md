# Security Policy

## Supported versions

Kaleidescape Companion is in alpha. Security fixes are considered for the
current `main` branch and the most recent tagged release on a best-effort basis.
Older pre-release versions may not receive fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include credentials,
household data, device addresses, logs, databases, or proof-of-concept details
in a public report.

Use GitHub's **Private vulnerability reporting** feature from the repository's
**Security** tab when it is available. If it is not available, open a public
issue requesting a private reporting channel without describing the
vulnerability; a maintainer will arrange a private conversation.

Include the affected version or commit, the relevant component, reproduction
steps, impact, and any mitigation you have identified. Please allow up to seven
days for an acknowledgement. The maintainer will provide status updates and
coordinate a fix or disclosure timeline based on severity and the alpha status
of the project.

## Scope

This policy covers this repository's integration source, packaged release
artifacts, and GitHub Actions workflows. Home Assistant Core, Kaleidescape
hardware, third-party services, and upstream dependencies should also be
reported to their respective maintainers when appropriate.
